# ML Training

Weekly sessions for learning to work with AI APIs in Python. The project includes Gemini and local Ollama summarizers, a single-document FitStyle AI RAG chat app, and a conversational multi-document RAG search tool.

## Setup

1. Install [uv](https://docs.astral.sh/uv/) and [Ollama](https://ollama.com/download).
2. Install the Python dependencies:

   ```bash
   uv sync
   ```

3. Copy `.env.example` to `.env` and add your Gemini key if you plan to use the Gemini summarizer.

   ```ini
   GEMINI_API_KEY=your_gemini_key
   GEMINI_MODEL=gemini-3.8-flash
   ```

4. Download the chat model used by the RAG app:

   ```bash
   ollama pull gemma3:4b
   ```

   Keep Ollama running while using the chat app. If you use a different model, update `CHAT_MODEL` in `src/rag_system/ask.py` to the exact name shown by `ollama list`.

## Run the applications

### FitStyle AI document chat

From the project root, run:

```bash
uv run streamlit run src/rag_system/app.py
```

The app opens in a browser. Ask questions about the FitStyle AI document; answers are generated by the local Ollama model and include source page numbers. Sentence Transformers creates question embeddings locally with `all-MiniLM-L6-v2`; the model is downloaded the first time it is used.

The repository includes a saved index (`embeddings.json` and `vectors.npy`), so you can start chatting without rebuilding it. To rebuild the index after changing the source PDF, run `embedding.py` from the RAG folder:

```bash
cd src/rag_system
uv run python embedding.py
```

### Multi-document conversational search

The conversational search scripts build an index from every PDF in `src/Conversational_system/docs/`. Each indexed passage records its document name and page number. Search uses the same local `all-MiniLM-L6-v2` model, while Ollama (`gemma3:1b`) rewrites follow-up questions and generates answers using recent conversation history.

To rebuild the multi-document index after adding or changing PDFs:

```bash
uv run python src/Conversational_system/embedding.py
```

To try the conversational search in the terminal:

```bash
uv run python src/Conversational_system/ask_conversational.py
```

Enter `exit` to end the chat. Keep Ollama running and pull the configured model with `ollama pull gemma3:1b` first. The first embedding run downloads the local Sentence Transformers model.

### Gemini summarizer

### Local Ollama summarizer

## Sessions

### Session 1: Gemini API connection and text summarizer

- Connected to the Gemini API using a key stored in `.env`.
- Learned the model parameters and what each one does:
  - `temperature`: controls randomness (low = consistent, high = creative).
  - `top_p`: selects from the smallest group of words whose probabilities add up to this value.
  - `top_k`: selects from the top K most likely words.
  - `max_output_tokens`: maximum response length.
  - `stop_sequences`: text that makes the model stop when a sequence appears.
  - `seed`: helps make responses repeatable.
  - `candidate_count`: number of responses returned.
  - `presence_penalty` and `frequency_penalty`: reduce repetition and encourage new wording.
  - `system_instruction`: fixed instructions that define the model's role and style.
- Built a summarizer that accepts pasted text and returns a short summary.
- Added a retry for `503` server-busy errors.

Branch: `session1`

### Session 1 assignment: Local model with Ollama

- Checked the machine's RAM, GPU, and free disk space to choose a suitable model.
- Installed Ollama and ran `gemma3:1b` (about 0.8 GB).
- Built a local summarizer using the `ollama` Python library.
- Compared the Gemini and Ollama setups:

| | Gemini | Ollama |
|---|---|---|
| Runs on | Google servers | Local machine |
| Needs | API key and internet | Ollama and enough RAM |
| Max length | `max_output_tokens` | `num_predict` |
| Instructions | `system_instruction` | `system` message |
| Parameters | `GenerateContentConfig(...)` | `options={...}` |
| Response | `response.text` | `response["message"]["content"]` |

- Small local models can be less accurate than Gemini, especially with long or Arabic text.

Branch: `session_1_assignment`

### Session 2: FitStyle AI RAG chat app

- Indexed the FitStyle AI documentation PDF by splitting its text into chunks and storing each chunk with its page number.
- Created normalized document vectors locally with Sentence Transformers `all-MiniLM-L6-v2`.
- Built semantic search to retrieve the six most relevant chunks for each question.
- Added a Streamlit chat interface with conversation history, source page references, a new-chat button, and FitStyle AI branding.
- Configured Ollama (`gemma3:4b`) to generate answers locally from the retrieved document context.
- Both document and question embeddings run locally; answer generation runs through Ollama.

Branch: `session2`

### Session 2 assignment: Multi-document conversational search

- Built a **conversational multi-document RAG system**. RAG means retrieval-augmented generation: the app finds relevant passages in the indexed PDFs and gives those passages to a language model to ground its answer.
- Indexed every PDF in `src/Conversational_system/docs/`, splitting extracted text into overlapping chunks and saving each chunk with its source filename and page number.
- Used the local Sentence Transformers embedding model **`all-MiniLM-L6-v2`** to create normalized vectors for both document passages and questions. This is the embedding model, not the answer-generating chat model.
- Retrieved the most relevant passages across the documents, with an optional filter to search within one selected source PDF.
- Added short-term conversation memory: the system uses up to the last three question-and-answer turns to rewrite follow-up questions (for example, resolving “what about its cost?” into a complete question) and maintain context while answering.
- Used Ollama's **`gemma3:1b`** model as the local chat model to rewrite follow-ups and generate answers from the retrieved passages. Answers include the source PDF names and page numbers.
- Included sample PDFs on FitStyle AI, ancient Egyptian history, cloud computing, the global coffee industry, and solar PV.

Branch: `session-2-assignment`

## Notes

- Ollama must be running with the model configured in the relevant chat script (`gemma3:4b` for FitStyle AI, `gemma3:1b` for conversational search).
- The first use of Sentence Transformers may download `all-MiniLM-L6-v2` and requires an internet connection.
- `.env` is local configuration and should never be committed.
