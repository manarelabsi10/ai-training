# ML Training

Weekly sessions for learning to work with AI APIs in Python. The project includes Gemini and local Ollama summarizers, plus a retrieval-augmented generation (RAG) chat app for the FitStyle AI documentation.

## Setup

1. Install [uv](https://docs.astral.sh/uv/) and [Ollama](https://ollama.com/download).
2. Install the Python dependencies:

   ```bash
   uv sync
   ```

3. Copy `.env.example` to `.env`. Add the OpenRouter key used to create question embeddings. The Gemini summarizer also needs its Gemini key.

   ```ini
   GEMINI_API_KEY=your_gemini_key
   GEMINI_MODEL=gemini-3.8-flash
   OPENROUTER_API_KEY=your_openrouter_key
   ```

4. Download the chat model used by the RAG app:

   ```bash
   ollama pull gemma3:4b
   ```

   Keep Ollama running while using the chat app. If you use a different model, update `CHAT_MODEL` in `src/rag_system/ask.py` to the exact name shown by `ollama list`.

## Run the applications

### FitStyle AI document chat

From the project root, run:

```bash
uv run streamlit run src/rag_system/app.py
```

The app opens in a browser. Ask questions about the FitStyle AI document; answers are generated by the local Ollama model and include source page numbers. Question embeddings are currently created through OpenRouter, so the chat needs an internet connection and a working `OPENROUTER_API_KEY`. OpenRouter's free model limits may apply.

The repository includes a saved index (`embeddings.json` and `vectors.npy`), so you can start chatting without rebuilding it. To rebuild the index after changing the source PDF, run `embedding.py` from the RAG folder with the OpenRouter key configured:

```bash
cd src/rag_system
uv run python embedding.py
```

### Gemini summarizer

```bash
uv run python src/test_app/main.py
```

### Local Ollama summarizer

```bash
ollama pull gemma3:1b
uv run python src/test_app/local.py
```

Paste the text in the terminal and type `END` on a new line to get a summary.

## Sessions

### Session 1: Gemini API connection and text summarizer

- Connected to the Gemini API using a key stored in `.env`.
- Learned the model parameters and what each one does:
  - `temperature`: controls randomness (low = consistent, high = creative).
  - `top_p`: selects from the smallest group of words whose probabilities add up to this value.
  - `top_k`: selects from the top K most likely words.
  - `max_output_tokens`: maximum response length.
  - `stop_sequences`: text that makes the model stop when a sequence appears.
  - `seed`: helps make responses repeatable.
  - `candidate_count`: number of responses returned.
  - `presence_penalty` and `frequency_penalty`: reduce repetition and encourage new wording.
  - `system_instruction`: fixed instructions that define the model's role and style.
- Built a summarizer that accepts pasted text and returns a short summary.
- Added a retry for `503` server-busy errors.

Branch: `session1`

### Session 1 assignment: Local model with Ollama

- Checked the machine's RAM, GPU, and free disk space to choose a suitable model.
- Installed Ollama and ran `gemma3:1b` (about 0.8 GB).
- Built a local summarizer using the `ollama` Python library.
- Compared the Gemini and Ollama setups:

| | Gemini | Ollama |
|---|---|---|
| Runs on | Google servers | Local machine |
| Needs | API key and internet | Ollama and enough RAM |
| Max length | `max_output_tokens` | `num_predict` |
| Instructions | `system_instruction` | `system` message |
| Parameters | `GenerateContentConfig(...)` | `options={...}` |
| Response | `response.text` | `response["message"]["content"]` |

- Small local models can be less accurate than Gemini, especially with long or Arabic text.

Branch: `session_1_assignment`

### Session 2: FitStyle AI RAG chat app

- Indexed the FitStyle AI documentation PDF by splitting its text into chunks and storing each chunk with its page number.
- Created normalized document vectors with the OpenRouter embedding model `nvidia/nemotron-3.5-embed-1b:free`.
- Built semantic search to retrieve the six most relevant chunks for each question.
- Added a Streamlit chat interface with conversation history, source page references, a new-chat button, and FitStyle AI branding.
- Configured Ollama (`gemma3:4b`) to generate answers locally from the retrieved document context.
- The embedding request still uses OpenRouter; only answer generation runs locally.

Branch: `session2`

## Notes

- Set `OPENROUTER_API_KEY` in `.env` before building the index or asking questions.
- The free OpenRouter embedding tier can enforce daily request limits.
- `.env` is local configuration and should never be committed.
